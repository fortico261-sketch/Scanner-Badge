backend du projet Scanner Badge.

## Stack

- Node.js
- TypeScript
- Prisma
- PostgreSQL
- Docker
- MQTT

## Démarrage

Lancer les services :  docker compose up -d
Vérifier les conteneurs :  docker ps

## Base de données

PostgreSQL est exécuté via Docker.
